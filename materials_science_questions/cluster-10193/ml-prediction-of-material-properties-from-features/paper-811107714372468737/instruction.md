# Virtual Screening for Grain Boundary Structure Prediction

## Problem background
Interfaces markedly affect material properties because of their distinct atomic configurations. Determining interface atomic structure usually requires extensive computation due to the high geometrical freedom (nine macroscopic and microscopic degrees of freedom). This task reproduces a virtual screening technique based on machine learning that predicts grain boundary energies and structures from initial atomic configuration descriptors. The predictor is trained on data from only four grain boundaries and applied to a set of 13 other grain boundaries, aiming to drastically reduce the number of explicit structure calculations needed.

## Approach
The method constructs an ε-support vector regression (ε-SVR) predictor with a Gaussian kernel using geometrical descriptors extracted from initial, unrelaxed grain boundary configurations. The training data are generated by all-candidate static lattice calculations with an embedded-atom method (EAM) potential for four training grain boundaries: Σ5(210), Σ5(310), Σ17(410), and Σ17(350). For each atomic configuration, an 83-component descriptor vector is computed from the initial atomic positions—including bond lengths, atomic density, and their squares, inverses, and exponentials. Descriptors are standardized to zero mean and unit variance, and a screened set of 800 descriptor-energy pairs is used to train the predictor. The predictor is then applied to each of the 13 test grain boundaries: all rigid-body translation configurations are scored, and for each boundary the configuration with the lowest predicted energy is selected. The predicted minimum grain boundary energy and the corresponding rigid-body translation state (X, Y, Z) are output to a CSV file.

## Reproduction target
Generate a CSV file `predictions.csv` with columns: `boundary` (string), `misorientation_angle` (float, degrees), `predicted_energy` (float, J/m²), `predicted_X` (float, Å), `predicted_Y` (float, Å), `predicted_Z` (float, Å). One row for each of the 13 test grain boundaries: Σ13/(230), Σ25/(430), Σ25/(710), Σ29/(520), Σ29/(730), Σ37/(610), Σ37/(750), Σ41/(910), Σ41/(540), Σ53/(720), Σ53/(950), Σ61/(11 1 0), Σ125/(11 2 0). The misorientation angles for these boundaries are: Σ61/(11 1 0) = 10.39°, Σ41/(910) = 12.68°, Σ25/(710) = 16.26°, Σ37/(610) = 18.92°, Σ125/(11 2 0) = 20.61°, Σ53/(720) = 31.89°, Σ29/(520) = 43.6°, Σ29/(730) = 46.4°, Σ53/(950) = 58.11°, Σ13/(230) = 67.38°, Σ37/(750) = 71.08°, Σ25/(430) = 73.74°, Σ41/(540) = 77.32°. The predicted energies must produce a convex misorientation-angle curve with a single maximum near 45° and must exhibit local minima (cusps) at specific misorientation angles reported in the literature. For the Σ13 boundary, the predicted minimum energy and translation state (X, Y, Z) will be compared against hidden reference values derived from the paper.

## Workflow steps

### Step 1: Generate initial rigid-body translation configurations for the training boundaries
- Role: process
- Action: Using the known supercell geometries for Σ5[001]/(210), Σ5[001]/(310), Σ17[001]/(350), Σ17[001]/(410) and the rigid-body translation grid (0.1 Å steps in x and z, 0.1 Å steps in y from 1.0 to 1.5 Å), create all possible initial (unrelaxed) atomic configurations.
- Evidence: none

### Step 2: Run all-candidate static lattice calculations for training boundaries
- Role: process
- Action: For each training configuration, perform energy minimization using LAMMPS with the Cu EAM potential. Keep atoms at the slab edges fixed and the cell volume fixed. Compute the grain boundary energy from the relaxed total energy.
- Evidence: none

### Step 3: Extract descriptors, standardize, and construct training set
- Role: process
- Action: For each training configuration, compute the 83-component descriptor vector (geometrical features as defined in the supplementary material, including squares, inverses, exponentials). Standardize all descriptor vectors to zero mean and unit variance. From the computed data, screen 800 descriptor-energy pairs (most stable and metastable configurations, prioritizing those with small atomic relaxation) to form the final training set for SVR.
- Evidence: none

### Step 4: Train ε-SVR predictor
- Role: process
- Action: Train an ε-SVR with a Gaussian (RBF) kernel using the prepared training set. Use grid search to select hyperparameters from the ranges described in the method. Save the fitted model.
- Evidence: `/app/outputs/trained_svr_model.pkl`

### Step 5: Generate test configurations and compute descriptors
- Role: process
- Action: For each of the 13 test grain boundaries (Σ13/(230), Σ25/(430), Σ25/(710), Σ29/(520), Σ29/(730), Σ37/(610), Σ37/(750), Σ41/(910), Σ41/(540), Σ53/(720), Σ53/(950), Σ61/(11 1 0), Σ125/(11 2 0)), generate all possible rigid-body translation configurations using the same grid. Compute the 83 descriptors for each configuration and standardize them using the parameters obtained in step_03.
- Evidence: none

### Step 6: Predict minimum energies and translation states (virtual screening)
- Role: scored (load-bearing)
- Action: Apply the trained SVR to predict grain boundary energies for all configurations of each test boundary. For each boundary, select the configuration with the lowest predicted energy. Write the results to predictions.csv with columns: boundary (string), misorientation_angle (float, degrees), predicted_energy (float, J/m²), predicted_X (float, Å), predicted_Y (float, Å), predicted_Z (float, Å). One row per test boundary (13 rows).
- Output file: `/app/outputs/predictions.csv`
- Format: csv

## How you are scored
A hidden verifier reads your `predictions.csv`. It independently: (1) analyses the energy vs. misorientation angle curve for overall convexity, the presence of a single maximum near 45°, and the existence of local minima (cusps) within a small tolerance of the expected misorientation angles; (2) for the Σ13 boundary, compares your predicted energy and translation state (X, Y, Z) to hidden reference values from the paper, with appropriate tolerances. The final score (0–1) is a weighted combination of these checks, with the structural curve properties carrying the majority weight. You must execute the entire workflow; a file that coincidentally matches the paper's numbers without following the method will not satisfy the structural checks.
