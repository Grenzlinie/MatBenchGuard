# Neural Network Reproduction of CFRP Elastic Coefficient Formulas

## Problem background
Designers of unidirectional carbon fiber reinforced plastics (CFRP) rely on closed-form composite formulas (rule of mixtures, reciprocal relations, and laminate theory) to compute elastic coefficients from fiber and matrix properties and the fiber volume fraction Vf. A data-driven representation or interpolation between sparse theoretical samples requires verifying whether a feedforward neural network can accurately learn and generalize the forward mapping from Vf and constituent moduli to the full set of elastic constants. Additionally, the inverse problem of determining Vf or fiber orientation angle θ from desired elastic coefficients is important for material design. This work addresses both the forward representational capability and the inverse design solutions using neural networks: the objective is to determine whether such networks can reproduce the analytical forward mapping and provide usable solutions to the inverse design problems.

## Approach
Three separate feedforward neural networks are constructed and trained on data computed from the analytical composite formulas using fixed material constants for T300 carbon fiber and epoxy resin. The networks use a multi-layer architecture with sigmoidal activation and are trained via error backpropagation. The forward network maps Vf (together with the fixed material constants) to the full set of elastic coefficients. Two inverse networks map triples of in-plane elastic coefficients (E11, E22, G12) to the design variables: one predicts Vf, the other predicts fiber orientation angle θ (with Vf held at 60% and using laminate theory for angle-ply laminates). Training data are generated by evaluating the analytical formulas at a set of Vf or θ values; the trained networks are then evaluated on held-out interpolated test points to assess generalization.

## Reproduction target
For each of the three neural network models (forward mapping, inverse Vf prediction, inverse angle prediction), implement the specified feedforward architecture, generate the training data from the analytical formulas using the provided material constants, train the networks, and evaluate them on the held-out test points described in the workflow steps. The objective is to produce predictions of elastic coefficients (forward) and of the design parameters Vf and θ (inverse) at those test points. Submit the predictions in three CSV files (forward_predictions.csv, inverse_Vf_predictions.csv, angle_predictions.csv) with the exact columns and formats specified in the workflow. The accuracy of the predictions will be assessed by comparing them to analytically computed target values; no paper figures or training curves need to be reproduced.

## Workflow steps

### Step 1: Generate forward network training data
- Role: process
- Action: Using the T300/Epoxy material constants (E_fL=225 GPa, E_fT=15.8 GPa, G_f=19.6 GPa, ν_fL=0.3, ν_fT=0.021, E_m=3.43 GPa, G_m=1.27 GPa, ν_m=0.36), compute the seven elastic coefficients E11, E22, G12, G23, ν12, ν21, ν23 via the rule-of-mixtures and reciprocal relations for fiber volume fractions Vf = 0%, 10%, ..., 100% (11 patterns). No output file.
- Evidence: none

### Step 2: Train forward neural network
- Role: process
- Action: Construct and train a feedforward neural network with an input layer, three hidden layers of 30 neurons each, and an output layer (five layers total). Use activation function f(u)=2/(1+e^{-u})-1 and thresholds h_i=0. Train with error backpropagation on the forward training data for enough iterations to achieve convergence. Save the trained model weights.
- Evidence: `/app/outputs/forward_model.pth`

### Step 3: Evaluate forward network on test Vf values
- Role: scored (load-bearing)
- Action: Using the trained forward network, predict the elastic coefficients for fiber volume fractions Vf = 5%, 15%, …, 95% (9 test points). Output predictions to forward_predictions.csv.
- Output file: `/app/outputs/forward_predictions.csv`
- Format: csv
- Contract: CSV with columns: Vf_pct (integer), E11_pred, E22_pred, G12_pred, G23_pred, nu12_pred, nu21_pred, nu23_pred (all floats, in GPa or dimensionless).
- Scoring: scored by hidden verifier

### Step 4: Generate inverse Vf training data
- Role: process
- Action: Using the same material constants and composite formulas, compute E11, E22, G12 for fiber volume fractions Vf = 30%, 40%, …, 80% (6 patterns). Create input-target pairs where inputs are (E11, E22, G12) and target is the corresponding Vf.
- Evidence: none

### Step 5: Train inverse Vf neural network
- Role: process
- Action: Construct and train a feedforward neural network with an input layer, three hidden layers of 50 neurons each, and an output layer (five layers total). Use same activation and training method. Train to map (E11, E22, G12) to Vf. Save the trained model weights.
- Evidence: `/app/outputs/inverse_vf_model.pth`

### Step 6: Evaluate inverse Vf network on test inputs
- Role: scored
- Action: For test Vf_true = 35%, 45%, 55%, 65%, 75%, compute the corresponding (E11, E22, G12) using the composite formulas. Feed these triples into the trained inverse Vf network to obtain Vf_pred. Output results to inverse_Vf_predictions.csv.
- Output file: `/app/outputs/inverse_Vf_predictions.csv`
- Format: csv
- Contract: CSV with columns: Vf_true (float, percent), E11_input (GPa), E22_input (GPa), G12_input (GPa), Vf_pred (float, percent).
- Scoring: scored by hidden verifier

### Step 7: Generate inverse angle training data
- Role: process
- Action: Fix Vf=60% and use the same material constants. For fiber orientation angles θ = 0°, 15°, …, 90° (7 patterns), compute laminate elastic coefficients E11, E22, G12 using laminate theory. Create input-target pairs where inputs are (E11, E22, G12) and target is θ.
- Evidence: none

### Step 8: Train inverse angle neural network
- Role: process
- Action: Construct and train a feedforward neural network with input layer, three hidden layers of 30 neurons each, and output layer (five layers total). Use same activation and training method. Train to map (E11, E22, G12) to θ. Save the trained model weights.
- Evidence: `/app/outputs/angle_model.pth`

### Step 9: Evaluate inverse angle network on test orientations
- Role: scored
- Action: For test θ_true = 5°, 20°, 35°, 50°, 65°, 80° (with Vf=60%), compute the corresponding (E11, E22, G12) using laminate theory. Feed these to the trained inverse angle network to predict θ. Output results to angle_predictions.csv.
- Output file: `/app/outputs/angle_predictions.csv`
- Format: csv
- Contract: CSV with columns: theta_true (degrees), E11_input (GPa), E22_input (GPa), G12_input (GPa), theta_pred (degrees).
- Scoring: scored by hidden verifier

## How you are scored
Each scored output file is evaluated independently by a hidden verifier. The verifier recomputes the true elastic coefficients and design parameters using the same analytical formulas and material constants, then compares your predictions to these analytically derived targets. Error metrics (relative and absolute errors appropriate to each output) are computed, and your submission is scored against hidden performance thresholds. Meeting or exceeding a threshold earns full credit for that stage; larger errors result in linearly decreased credit. The overall reward is a weighted combination of the stage scores. This scoring design ensures that a faithful re-execution of the required procedure will score well, while guesses or fabrications are unlikely to meet the thresholds. Simply reporting numbers from the paper is not sufficient — the verifier checks the predictions you actually produce.
