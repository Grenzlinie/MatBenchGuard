# First-principles properties of zinc-blende InAs_xSb_{1-x} ternary alloys: structural, electronic, mechanical, thermodynamic and nonlinear optical coefficients

## Problem background
III-V semiconductor alloys are important in optoelectronics and infrared devices. The cubic zinc-blende InAs<sub>x</sub>Sb<sub>1-x</sub> system combines InAs (smaller lattice constant, larger band gap) with InSb (larger lattice constant, smaller band gap) to create alloys with continuously tunable structural, electronic, mechanical, thermal, and optical properties. Reliably predicting these properties from first principles is challenging because some effects depend sensitively on the treatment of semicore states (In 4d). This work uses density functional theory (DFT) and density functional perturbation theory (DFPT) to compute a comprehensive set of physical quantities across the full composition range, revealing trends and the impact of pseudopotential choice. The reproduction task is to run the same computational protocol and report all computed property values in a standardized format.

## Approach
Computations are performed with the open-source ABINIT plane-wave pseudopotential code. Alloy disorder is treated by the virtual crystal approximation (VCA): pseudopotentials for InAs<sub>x</sub>Sb<sub>1-x</sub> are generated by linearly mixing the ionic pseudopotentials of As and Sb at each composition x (0, 0.25, 0.5, 0.75, 1). Two norm-conserving pseudopotential families are employed: Hartwigsen-Goedecker-Hutter (HGH) and Troullier-Martins-type (FHI), the latter including In 4d semicore states. For each composition and pseudopotential, the workflow consists of: (i) DFT-LDA geometry relaxation to obtain equilibrium lattice constants; (ii) Kohn-Sham band structure at the relaxed geometry to extract the LDA band gap; (iii) one-shot G<sub>0</sub>W<sub>0</sub> quasiparticle correction to improve the band gap; (iv) DFPT linear response to compute phonon frequencies at Γ, static and high-frequency dielectric constants, and Born effective charges; (v) total-energy versus strain fits to obtain the elastic constants C<sub>11</sub>, C<sub>12</sub>, C<sub>44</sub> and derived mechanical quantities (bulk and shear moduli, Pugh ratio, Cauchy pressure); (vi) thermodynamic functions C<sub>v</sub> and S at 300 K from the phonon density of states in the harmonic approximation; and (vii) DFPT nonlinear response (2n+1 theorem) to obtain the second-order optical susceptibility d<sub>36</sub>, Raman susceptibilities for TO and LO modes, and the clamped electro-optic coefficient r<sub>63</sub><sup>s</sup> (electronic, ionic, total). The approach separately evaluates the HGH and FHI schemes to assess the influence of In 4d states. All final results are aggregated into a single JSON file.

## Reproduction target
For the five compositions x = 0, 0.25, 0.5, 0.75, 1, compute all quantities listed in the output contract using both the HGH and FHI pseudopotential schemes, and write them to the single JSON file `/app/outputs/computed_properties.json`. The required quantities cover: equilibrium lattice parameters; band gaps from HGH.LDA, HGH.G<sub>0</sub>W<sub>0</sub>, and FHI.G<sub>0</sub>W<sub>0</sub>; static and high-frequency dielectric constants (HGH); Born effective charge (HGH); TO and LO phonon frequencies at Γ (HGH); specific heat at constant volume C<sub>v</sub> and entropy S both at T = 300 K (HGH); elastic constants C<sub>11</sub>, C<sub>12</sub>, C<sub>44</sub>, isotropic bulk modulus B, shear modulus G, B/G ratio, and Cauchy pressure C<sub>12</sub>-C<sub>44</sub> (HGH); and nonlinear optical properties d<sub>36</sub>, Raman susceptibilities α(ω<sub>TO</sub>), α(ω<sub>LO</sub>), and clamped electro-optic coefficients r<sub>63</sub><sup>s</sup> (electronic, ionic, total), each evaluated with both HGH and FHI schemes. All values should be reported as numbers in the units and array order defined in the output contract.

## Workflow steps

### Step 1: Virtual crystal approximation pseudopotential construction
- Role: process
- Action: Using ABINIT, generate VCA pseudopotentials for InAs_xSb_{1-x} at compositions x = 0, 0.25, 0.5, 0.75, 1 by linearly mixing the ionic pseudopotentials of As and Sb (V_VCA = x V_As + (1-x) V_Sb) for both HGH and FHI pseudopotential schemes.
- Evidence: `/app/outputs/vca_hgh.log`

### Step 2: DFT geometry optimization
- Role: process
- Action: Perform DFT-LDA geometry relaxation for each composition and pseudopotential using the VCA potentials. Save the relaxed structures and equilibrium lattice constants.
- Evidence: `/app/outputs/relax.log`

### Step 3: LDA band structure calculation
- Role: process
- Action: Compute the Kohn-Sham band structure at the relaxed geometry using the HGH pseudopotential. Extract the LDA band gap at the Gamma point for each composition.
- Evidence: `/app/outputs/lda_bandgap.csv`

### Step 4: GW quasiparticle correction
- Role: process
- Action: Perform one-shot G0W0 calculations on top of the HGH.LDA and FHI.LDA wavefunctions for all compositions. Obtain GW-corrected band gaps.
- Evidence: `/app/outputs/gw_bandgap.csv`

### Step 5: DFPT linear response: phonons, dielectric constants, Born effective charges
- Role: process
- Action: Run DFPT linear response for all compositions using HGH pseudopotentials. Compute TO and LO phonon frequencies at Gamma, static dielectric constant, and Born effective charges.
- Evidence: `/app/outputs/dfpt_linear.log`

### Step 6: Elastic constants calculation
- Role: process
- Action: Calculate the three independent elastic constants C11, C12, C44 for each composition using HGH pseudopotentials by applying small strains to the relaxed unit cell and fitting the resulting total energy changes.
- Evidence: `/app/outputs/elastic_constants.csv`

### Step 7: DFPT nonlinear optical and electro-optic properties
- Role: process
- Action: Using DFPT with the 2n+1 theorem, compute the second-order optical susceptibility d36, Raman susceptibilities for TO and LO modes, and the clamped electro-optic coefficient r63^s (electronic, ionic, total) for all compositions and both HGH and FHI pseudopotentials.
- Evidence: `/app/outputs/nonlinear_optical.csv`

### Step 8: Aggregate all computed properties into a single JSON file
- Role: scored (load-bearing)
- Action: Collect all numerical results from the preceding steps and write them into a single JSON file following the output contract schema.
- Output file: `/app/outputs/computed_properties.json`
- Format: json
- Contract: A JSON object with keys: lattice_parameters, band_gaps, dielectric_constants, born_effective_charge, phonon_frequencies, thermodynamic_300K, elastic_constants, nonlinear_optical. Each value is an array of five floats (for x=0,0.25,0.5,0.75,1) or nested objects for different pseudopotential schemes/methods.
- Scoring: scored by hidden verifier
