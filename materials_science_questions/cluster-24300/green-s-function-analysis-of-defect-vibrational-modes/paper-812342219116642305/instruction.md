# Microwave NDE Defect Reconstruction Using Numerically Computed Green's Function

## Problem background
In microwave nondestructive evaluation (NDE), a known host medium may contain defects that alter the scattered electromagnetic field. Reconstructing the defect's location, size and orientation from scattered-field measurements is an inverse problem. Traditional methods often use the free-space Green's function, which does not encode the host's material properties, potentially limiting accuracy. This task implements a reconstruction pipeline that numerically computes an inhomogeneous Green's function incorporating the host's geometry and dielectric properties, uses it to generate synthetic scattered field data, and then employs a genetic algorithm (GA) to estimate defect parameters. The goal is to quantitatively compare reconstruction accuracy and convergence when the inversion uses the host-aware kernel (IGA) versus the free-space kernel (FGA).

## Approach
The method first computes the Green's function for the unperturbed host medium offline by solving an integral equation with the method of moments. Synthetic scattered field data (generated from a hidden defect) is provided as input to the agent. The inverse problem is then solved with a genetic algorithm that searches for the defect's center coordinates, width, length, orientation, and the internal total field, minimizing a cost functional that combines data and state equations. Two inversion variants are compared: IGA uses the precomputed inhomogeneous Green's function; FGA uses the analytically known free-space Green's function. The host configurations tested are two lossy media: both have relative permittivity ε_I=2.0, and conductivities of σ_I=0.25 S/m and σ_I=0.5 S/m. Synthetic measurement noise is added to achieve an SNR of 25 dB.

The hidden verifier will use these entries to compute the defect localization error δ_c, area error δ_a, and convergence improvement Δ_conv, and will score your reconstruction accuracy and convergence relative to the paper's reported results.

- Role: process
- Action: Numerically solve the integral equation for the host medium's Green's function using the moment method for the two specified host configurations (σ_I=0.25 S/m, ε_I=2.0 and σ_I=0.5 S/m, ε_I=2.0). The free-space Green's function Γ0 is known analytically.

No further noise addition is required; the data already includes synthetic noise at SNR=25 dB.
- Evidence: none

### Step 3: Run IGA Inversion
- Role: process
- Action: For both host scenarios, run the genetic algorithm inversion using the inhomogeneous Green's function (IGA). Optimize the defect parameters (center coordinates, width, length, orientation) and the internal total field. Use GA settings: population size 20, mutation probability 0.4, maximum iterations 200. Record the estimated parameters, final cost function value, and number of iterations at convergence.
- Evidence: `/app/outputs/iga_results.json`

### Step 4: Run FGA Inversion
- Role: process
- Action: For both host scenarios, run the same genetic algorithm but using the free-space Green's function (FGA) instead of the inhomogeneous kernel. All other parameters remain identical. Record the estimated parameters, final cost, and iteration count.
- Evidence: `/app/outputs/fga_results.json`

### Step 5: Assemble and Export Reconstruction Results
- Role: scored (load-bearing)
- Action: Collect the reconstructed defect parameters, iteration counts, and final functional values from the IGA and FGA runs (steps 3 and 4) for both host scenarios and write them to a JSON file with the schema described in the output contract.
- Output file: `/app/outputs/reconstructions.json`
- Format: json
- Contract: JSON array of objects, each with fields: scenario (string, 'sigI0.25_SNR25' or 'sigI0.5_SNR25'), method (string, 'IGA' or 'FGA'), center_x (float), center_y (float), width (float), length (float), orientation (float), iterations (int), final_functional (float). Must contain exactly 4 entries: two scenarios × two methods.
- Scoring: scored by hidden verifier

## How you are scored
A hidden verifier program reads your `/app/outputs/reconstructions.json`, recomputes the center location error δ_c, area error δ_a, and convergence improvement Δ_conv for each host scenario (pairing IGA and FGA entries). It compares these metrics to the paper's reported results using directional tolerances: lower δ_c and δ_a are better, while higher Δ_conv is better. If your computed metrics meet or beat the expected thresholds, you receive full credit for that scenario; performance below the threshold yields partial credit. The two scenarios are weighted equally, and the total reward ranges from 0.0 to 1.0. The exact tolerances and gold values are hidden; your goal is to faithfully implement the pipeline so that your reconstruction results are as accurate as those reported in the paper.
