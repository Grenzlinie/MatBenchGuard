# Temperature‑Dependent Modal Polarization Properties of Highly Elliptical‑Core Fibers

## Problem background
Understanding how modal birefringence and polarization mode dispersion (PMD) in highly elliptical-core optical fibers change with temperature is essential for designing white-light interferometric sensors. This task focuses on computing the temperature-dependent modal properties of a specific fiber (Andrew ET-800) and, from them, the relative temperature sensitivities. The challenge is to account simultaneously for the geometric index profile and the temperature-induced stress modifications through the photoelastic effect, using a full-vectorial numerical approach.

## Approach
The task follows a four-stage computational pipeline. First, the thermal stress distribution across the fiber cross-section is computed at several ambient temperatures using the analytical thermo-elastic solution of Tsai et al. (1991). Second, the stress field is converted into position- and temperature-dependent refractive index distributions via the photoelastic model, yielding the diagonal components of the anisotropic dielectric tensor. Third, the vectorial Maxwell equations (coupled partial differential equations for the longitudinal field components) are solved numerically to obtain the propagation constants of the two polarization modes, using a forced-steady-state β-scan method that identifies guided-mode eigenvalues as sharp peaks in a field norm. Finally, at each temperature, modal birefringence B and PMD τ are calculated at a central wavelength of 826 nm (with the wavelength derivative estimated from nearby wavelengths) and written to a CSV file. The verifier will subsequently derive the temperature sensitivities from this data.

### Step 2: Calculate stress‑modified refractive index distributions
- Role: process
- Action: For each ambient temperature, convert the stress components to principal stresses via σ₁,₂ = (σ_x+σ_y)/2 ± √[((σ_x-σ_y)/2)²+τ_xy²], apply the photoelastic model n₁ = n + C₁σ₁ + C₂σ₂, n₂ = n + C₁σ₂ + C₂σ₁, n₃ = n + C₂(σ₁+σ₂) with C₁ = -6.7×10⁻⁶ kg/mm², C₂ = -41.1×10⁻⁶ kg/mm², and the isotropic core/cladding index profile derived from Δn = 0.03. Rotate to Cartesian coordinates using the stress‑dependent transformation and take the diagonal elements n_x, n_y, n_z as 2D arrays.
- Evidence: none

### Step 3: Solve vectorial Maxwell equations for propagation constants
- Role: process
- Action: For each ambient temperature T, discretize the coupled longitudinal‑field PDEs (3)–(4) using a finite‑element or finite‑difference scheme. For wavelengths around 826 nm (e.g., 816, 826, 836 nm), perform a β‑scan: replace the homogeneous RHS with random nonzero functions, solve the forced steady‑state system for trial β, compute the norm ∫ |e_z| dx dy, and locate the sharp peaks corresponding to the x‑ and y‑polarized guided modes, yielding β_x(T,λ) and β_y(T,λ).
