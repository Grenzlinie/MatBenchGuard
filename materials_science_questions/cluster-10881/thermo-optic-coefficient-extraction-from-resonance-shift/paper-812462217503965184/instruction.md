# Temperature-Dependent Modal Polarization Properties of Highly Elliptical-Core Fibers

## Problem background
Understanding how modal birefringence and polarization mode dispersion (PMD) in highly elliptical-core optical fibers change with temperature is essential for designing white-light interferometric sensors. This task focuses on computing the temperature-dependent modal properties of a specific fiber (Andrew ET-800) and, from them, the relative temperature sensitivities. The challenge is to account simultaneously for the geometric index profile and the temperature-induced stress modifications through the photoelastic effect, using a full-vectorial numerical approach.

## Approach
The task follows a four-stage computational pipeline. First, the thermal stress distribution across the fiber cross-section is computed at several ambient temperatures by solving the plane-strain elasticity equations with the specified material constants and geometry. Second, the stress field is converted into position- and temperature-dependent refractive index distributions via the photoelastic model, yielding the diagonal components of the anisotropic dielectric tensor. Third, the vectorial Maxwell equations (coupled partial differential equations for the longitudinal field components) are solved numerically to obtain the propagation constants of the two polarization modes, using a forced-steady-state β-scan method that identifies guided-mode eigenvalues as sharp peaks in a field norm. Finally, at each temperature, modal birefringence B and PMD τ are calculated at a central wavelength of 826 nm (with the wavelength derivative estimated from nearby wavelengths) and written to a CSV file. The verifier will subsequently derive the temperature sensitivities from this data.

## Workflow steps

### Step 1: Compute thermal stress field
- Role: process
- Action:
  Compute the Cartesian thermal stress components σ_x(x,y), σ_y(x,y), τ_xy(x,y) over the fiber cross‑section for ambient temperatures T = 10, 20, 30, 40, 50 °C.

  **Fiber geometry and material parameters:**
  - Elliptical core: semi-major axis a = 3.0 μm, semi-minor axis b = 1.5 μm.
  - Outer cladding radius: 40 μm.
  - Core and cladding are assumed homogeneous and isotropic, with identical elastic properties:
    - Young’s modulus E = 7750 kg/mm² = 7.75×10¹⁰ Pa
    - Poisson’s ratio ν = 0.186
  - The thermal expansion mismatch is characterized by Δα = α_core − α_clad = 1.585×10⁻⁶ °C⁻¹.
    (Set α_clad = 0 as reference; the induced stress scales with Δα.)
  - Stress scales linearly with ΔT = T_room − T_soft. Here T_room is the ambient temperature T, and the glass softening temperature T_soft ≈ 870 °C.
    Hence ΔT = T − 870 °C (negative; cooling from softening point).

  **Governing equations (plane strain – fiber length is large, no axial strain):**
  In the absence of body forces, the stresses satisfy the equilibrium equations:
  ```
  ∂σ_x/∂x + ∂τ_xy/∂y = 0
  ∂τ_xy/∂x + ∂σ_y/∂y = 0
  ```
  The total strain is the sum of elastic and thermal parts. For plane strain:
  ```
  ε_x = (1/E)[(1−ν²)σ_x − ν(1+ν)σ_y] + α ΔT
  ε_y = (1/E)[(1−ν²)σ_y − ν(1+ν)σ_x] + α ΔT
  γ_xy = (2(1+ν)/E) τ_xy
  ```
  where α = α_core inside the core and α = α_clad = 0 in the cladding. The compatibility equation must be satisfied.

  **Boundary conditions:**
  - At the outer radius r = 40 μm: traction‑free surface → σ_rr = 0, τ_rθ = 0.
  - Stresses and displacements are continuous across the core–cladding interface.

  **Numerical implementation:**
  Solve the above boundary‑value problem on a 2D mesh encompassing the elliptical core and the circular cladding. You may use a finite‑difference or finite‑element method (e.g., assemble the stiffness matrix with thermal load vector and solve for displacements, then compute stresses). Because the problem is linear, you can compute a reference stress field for one ΔT = −1 °C and scale results proportionally for each T. The output is σ_x(x,y), σ_y(x,y), τ_xy(x,y) for each temperature.
- Evidence: none

### Step 2: Calculate stress‑modified refractive index distributions
- Role: process
- Action:
  For each ambient temperature T, convert the stress components to an anisotropic refractive index distribution using the photoelastic relations.

  **Principal stress calculation:**
  From σ_x, σ_y, τ_xy, the principal stresses are
  ```
  σ₁,₂ = (σ_x + σ_y)/2 ± √[((σ_x − σ_y)/2)² + τ_xy²]   (9)
  ```
  **Photoelastic effect (eqs. (5)–(7)):**
  ```
  n₁ = n⁽⁰⁾ + C₁σ₁ + C₂σ₂   (5)
  n₂ = n⁽⁰⁾ + C₁σ₂ + C₂σ₁   (6)
  n₃ = n⁽⁰⁾ + C₂(σ₁ + σ₂)   (7)
  ```
  where the unstressed isotropic index n⁽⁰⁾ equals n_core = 1.488 inside the core and n_clad = 1.458 in the cladding (Δn = 0.03). The photoelastic constants are:
  ```
  C₁ = −6.7×10⁻⁶ kg/mm²  = −6.7×10⁻¹² Pa⁻¹
  C₂ = −41.1×10⁻⁶ kg/mm² = −41.1×10⁻¹² Pa⁻¹
  ```

  **Transformation to Cartesian coordinates (eqs. (10)–(13)):**
  The rotation matrix that diagonalizes the stress tensor is
  ```
  [T] = [  α   β   0
         −β   α   0
          0   0   1 ]   (11)
  ```
  with
  ```
  α = ±(1 − τ_xy² / (2(σ_x−σ_y)²))   (12)
  β = ± τ_xy / (σ_x−σ_y)          (13)
  ```
  The Cartesian dielectric tensor components are obtained from
  ```
  [ε]_xyz = [T]⁻¹ diag(n₁², n₂², n₃²) [T]   (10)
  ```
  The diagonal elements of this tensor give n_x², n_y², n_z² (the off‑diagonal elements are neglected, as argued in the paper). Thus
  ```
  n_x² = α² n₁² + β² n₂²
  n_y² = β² n₁² + α² n₂²
  n_z² = n₃²
  ```
  The resulting n_x, n_y, n_z vary with position and temperature.
- Evidence: none

### Step 3: Solve vectorial Maxwell equations for propagation constants
- Role: process
- Action:
  For each ambient temperature T and for wavelengths around 826 nm (at least 816, 826, 836 nm), solve the coupled longitudinal‑field equations to obtain the propagation constants of the two orthogonally polarized fundamental modes.

  **Governing equations (eqs. (3)–(4)):**
  ```
   ∂  /        β² \ ∂e_z     β  ∂h_z \      ∂  /        β² \ ∂e_z     β  ∂h_z \
  ---| ( 1 + ---- ) ----- − ---- ---- |  − ---| ( 1 + ---- ) ----- + ---- ---- | − β h_z = 0   (3)
   ∂x \       p_y  /  ∂y      p_y  ∂x  /     ∂y \       p_x  /  ∂x      p_x  ∂y  /
  ```
  ```
   ∂  /        β² \ ∂e_z     β  ∂h_z \     ∂  /        β² \ ∂e_z     β  ∂h_z \
  ---| ( 1 + ---- ) ----- + ---- ---- | + ---| ( 1 + ---- ) ----- − ---- ---- | + k² n_z² e_z = 0   (4)
   ∂x \       p_x  /  ∂x      p_x  ∂y  /    ∂y \       p_y  /  ∂y      p_y  ∂x  /
  ```
  where k = 2π/λ, p_x = k² n_x² − β², p_y = k² n_y² − β², and n_x, n_y, n_z are the temperature‑ and position‑dependent refractive indices from Step 2.

  **Numerical method: forced‑steady‑state β‑scan**
  - Discretize the 2D domain with a finite‑element or finite‑difference mesh.
  - For a trial β, replace the zero on the right‑hand sides of (3)–(4) with random nonzero source functions, solve the linear system for e_z(x,y), h_z(x,y), and compute the field norm I(β) = ∫∫ |e_z| dx dy over the cross‑section.
  - Sweep β in the range [k·n_clad, k·n_core] (adjust slightly for temperature variation). Guided modes appear as sharp peaks in I(β). Identify the two highest peaks corresponding to the x‑polarized and y‑polarized fundamental modes; label their β as β_x(T,λ) and β_y(T,λ).
  - Repeat for each temperature and each wavelength (816, 826, 836 nm) to capture the wavelength dependence.
- Evidence: none

### Step 4: Compute B, τ and write scored CSV
- Role: scored (load-bearing)
- Action:
  For each temperature T ∈ {10, 20, 30, 40, 50} °C, use the dispersion curves β_x(λ), β_y(λ) to calculate the modal birefringence and PMD at λ₀ = 826 nm.

  **Definitions:**
  ```
  B(T) = (λ₀/(2π)) [β_x(T,λ₀) − β_y(T,λ₀)]          (dimensionless)
  dB/dλ ≈ [B(T,λ₀+Δλ) − B(T,λ₀−Δλ)]/(2Δλ)          (central difference, Δλ = 10 nm)
  τ(T) = (1/c) (B − λ₀ dB/dλ)                        (ps/m)
  ```
  where c = 2.99792458×10⁸ m/s.

  Write a CSV file `temperature_scan_results.csv` with exactly 5 rows (T = 10, 20, 30, 40, 50) and columns:
  - `T`: integer °C
  - `B`: dimensionless real number
  - `tau`: real number in ps/m

  Output file: `/app/outputs/temperature_scan_results.csv`
  Format: csv
  Contract: CSV with header: `T,B,tau`.
  Scoring: scored by hidden verifier
- Evidence: none
