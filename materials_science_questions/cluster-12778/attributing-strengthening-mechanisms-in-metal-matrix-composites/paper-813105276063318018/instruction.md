# Polycrystalline Transformation Strain from Lattice Constants

## Problem background
Ti-Ni-Cu shape memory alloys undergo a martensitic transformation from a cubic B2 parent phase to a monoclinic B19' martensite, which produces a transformation strain. The magnitude of this strain depends on the lattice parameters of both phases and on the orientation distribution of martensite variants in a polycrystal. To decouple the purely geometric contribution of lattice distortion from microstructural effects, the polycrystalline maximum martensitic transformation strain ε̄_M can be computed from measured lattice constants using a lattice-distortion model and averaging over representative crystal orientations. This computation reveals how much of the observed composition dependence of the transformation strain could be attributed to changes in the lattice parameters alone. Your task is to calculate ε̄_M for a series of Ti-Ni-Cu alloys with different Ti contents, using their experimentally determined lattice constants, and to produce a table of the resulting strains.

## Approach
The calculation follows a geometric lattice-distortion model. For each alloy, the B2 lattice constant a₀ and the B19' lattice constants a, b, c, and the monoclinic angle β are used to construct the distortion matrix T′ expressed in the martensite coordinate system:

T′ = [[a/a₀, 0, (c sinβ) / (tanβ · √2 a₀)],
      [0, b/(√2 a₀), 0],
      [0, 0, (c sinβ) / (√2 a₀)]].

A fixed orthogonal matrix R transforms from martensite coordinates to the parent B2 coordinates:

R = [[-1, 0, 0],
     [0, 1/√2, -1/√2],
     [0, -1/√2, 1/√2]].

The distortion matrix in parent coordinates is T = R T′ Rᵀ.

To ensure deterministic scoring, the 36 orientations must be generated by a specific regular grid in the unit triangle on the sphere with vertices:
  v0 = (0, 0, 1)     # [001]
  v1 = (0, 1/√2, 1/√2)  # [011]
  v2 = (1/√3, 1/√3, 1/√3) # [111]
Using n = 8 divisions per edge, create barycentric coordinates (u, v, w) with u = i/(n-1), v = j/(n-1), w = 1-u-v for i = 0..n-1, j = 0..(n-1-i). For each (i, j) compute the Cartesian direction before normalization: xyz = u·v1 + v·v2 + w·v0, then normalize to unit length. This yields exactly 36 distinct unit vectors. Use these 36 directions as the orientations x. For each orientation, compute the directional transformation strain ε_M^i = (|T x| - |x|) / |x|, then the polycrystalline maximum transformation strain ε̄_M = (1/36) Σ ε_M^i.
