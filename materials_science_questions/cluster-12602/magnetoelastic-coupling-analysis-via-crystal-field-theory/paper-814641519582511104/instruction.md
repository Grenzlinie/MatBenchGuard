# Microscopic magnetoelastic coupling analysis for BiFeO3

## Problem background
Magnetoelastic coupling, the interdependence between magnetic order and crystal lattice strain, governs phenomena such as magnetostriction, negative thermal expansion, and magnetoelectric effects in multiferroics. A first‑principles microscopic model is needed to quantify how a given spin configuration deforms the lattice and induces electric polarization. This task reproduces the computed magnetoelastic response for the room‑temperature multiferroic BiFeO₃ in its rhombohedral R3c structure. Specifically, the goal is to compute the derivatives of the nearest‑neighbor Fe–Fe exchange interaction with respect to strain, the stress generated by the G‑type antiferromagnetic (AFM) order, and the resulting spin‑order‑induced electric polarization decomposed into electronic, ion‑displacement, and lattice‑deformation contributions. Additionally, the quadratic dependence of the polarization change on an applied magnetic field is to be determined. All quantities are obtained from first‑principles density functional theory (DFT) calculations augmented by a linear magnetoelastic model.

## Approach
The total energy of a magnetic crystal is expanded around the paramagnetic (PM) equilibrium state as a sum of a lattice term (described by force constants, elastic constants, internal‑displacement tensors, Born effective charges, and piezoelectric coefficients) and a spin‑dependent term that depends on exchange interactions and their derivatives with respect to atomic displacements and strain. Truncating to first order in the displacements and strains and neglecting higher‑order spin‑lattice couplings yields a linear system of equations that relate the induced static displacements and homogeneous strains directly to the spin‑order‑averaged exchange‑parameter derivatives. Solving this linear system with the PM lattice coefficients and the exchange‑parameter derivatives yields the lattice deformation induced by a given spin order.

The workflow involves: (i) computing the PM‑state lattice coefficients for BiFeO₃ using DFT/DFPT; (ii) extracting the derivatives of the nearest‑neighbor Fe–Fe exchange parameter with respect to the six Voigt strain components via the four‑states mapping approach (where only the spin configuration of a chosen Fe pair is altered, and Hellmann‑Feynman stresses are collected); (iii) evaluating the total stress from the G‑type AFM order and solving the linear equations to obtain the strains and ion displacements; (iv) computing the three polarization contributions: the pure electronic part via Berry‑phase calculation with the G‑AFM spin order, the ion‑displacement part from Born effective charges and the solved displacements, and the lattice‑deformation part from the piezoelectric tensor and the solved strain; (v) performing independent DFT calculations on the G‑AFM state (including structural relaxation) to directly verify the three contributions; and (vi) analyzing the quadratic magnetoelectric coupling using a simplified spin Hamiltonian (nearest‑neighbor exchange plus Zeeman term) to obtain the polarization change as a function of magnetic field up to 20 T.

The workflow uses the open‑source DFT code Quantum ESPRESSO, standard pseudopotentials for Bi, Fe, and O, and the R3c crystal structure of BiFeO₃ (available from public databases). No specific numerical convergence parameters are mandated; the agent selects k‑point mesh, energy cutoffs, etc., appropriate to achieve converged stresses and polarizations.

## Workflow steps

### Step 1: Calculate paramagnetic-state lattice coefficients
- Role: process
- Action: Perform DFT calculations on the BiFeO3 R3c unit cell (or a suitable supercell) in the paramagnetic reference state. Compute the force‑constant matrix, frozen‑ion elastic constants, internal‑displacement tensor, Born effective charge tensors, and frozen‑ion piezoelectric tensor using density‑functional perturbation theory or finite‑difference methods. Save all tensors in a structured JSON file for later use.
- Evidence: `/app/outputs/paramagnetic_coefficients.json`

### Step 2: Compute exchange-parameter derivatives and stress
- Role: scored
- Action: Using the four‑states mapping approach, compute the first‑order derivatives of the nearest‑neighbor Fe‑Fe exchange parameter J_NN with respect to the six Voigt strain components η_j. For each of the four spin configurations, run a DFT calculation on the paramagnetic equilibrium structure and extract the Hellmann‑Feynman stress. Then compute the total stress σ_j induced by the G‑type AFM order by summing over nearest‑neighbor pairs. Output the derivatives and model stress in the specified JSON file.
- Output file: `/app/outputs/step_01_magnetoelastic_params.json`
- Format: json
- Contract: {"dJ_deta": [float,6] (eV), "stress_model": [float,6] (kbar)}
- Scoring: scored by hidden verifier

### Step 3: Spin-order-induced polarization contributions
- Role: scored (load-bearing)
- Action: Compute the three contributions to the electric polarization induced by the G‑type AFM order in BiFeO3. (a) Electronic contribution: perform a Berry‑phase DFT calculation on the R3c structure with G‑AFM spins. (b) Solve the linear magnetoelastic equations using the paramagnetic coefficients and exchange derivatives to obtain atomic displacements and homogeneous strains; then compute the ion‑displacement polarization via Born effective charges and the lattice‑deformation polarization via the piezoelectric tensor. (c) Direct DFT verification: run independent DFT calculations (including structural relaxation) for the G‑AFM state to independently evaluate the electronic, ionic, and lattice‑deformation contributions. Output all six values in a JSON file.
- Output file: `/app/outputs/step_02_polarization_contributions.json`
- Format: json
- Contract: {"model_lattice": float, "model_electronic": float, "model_ionic": float, "dft_lattice": float, "dft_electronic": float, "dft_ionic": float} (all μC/cm²)
- Scoring: scored by hidden verifier

### Step 4: Quadratic magnetoelectric coupling
- Role: scored
- Action: Using a simplified spin Hamiltonian (nearest‑neighbor exchange plus Zeeman term) and the known G‑type AFM arrangement, derive the relation between spin angle and applied magnetic field H. From the magnetoelastic model, the spin‑induced polarization is proportional to the spin‑pair correlation, leading to ΔP ∝ H². Compute the polarization change ΔP(H) relative to zero field for H = 0, 5, 10, 15, 20 T. Output the data as a CSV file.
- Output file: `/app/outputs/step_03_field_dependence.csv`
- Format: csv
- Contract: columns: H_T (float), DeltaP_muC_cm2 (float); at least rows for H = [0, 5, 10, 15, 20]
- Scoring: scored by hidden verifier
