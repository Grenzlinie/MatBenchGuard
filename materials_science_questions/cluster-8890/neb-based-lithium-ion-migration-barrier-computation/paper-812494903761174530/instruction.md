# Lithium Argyrodite Stability and Elastic Property Prediction via DFT and Soft-Mode Displacement

## Problem background
Lithium argyrodites are a broad family of solid electrolytes where Li-ion conductivity is often linked to dynamic cation disorder. A structural analogy between the cubic argyrodite and cubic antiperovskite phases suggests that hexagonal analogues can be formed by switching from cubic to hexagonal stacking of close-packed Li3X and Li3SiO4 layers. This study explores that analogy by designing candidate hexagonal argyrodite compositions Li6SiO4XX' (X,X' = F, Cl, Br, I) with a 4H-type stacking motif. The key computationally predicted properties are: (i) their thermodynamic stability against decomposition into Li4SiO4 + LiX + LiX', and (ii) the elastic bulk and shear moduli of the most stable predicted phase. This task requires computing those quantities from first principles.

## Approach
The approach is based on plane-wave density functional theory (DFT) with the PBE functional. First, structural models are built for Li6SiO4XX' in the high-symmetry space group P63mc, with alternating Li3X and Li3SiO4 layers and ordered half-occupation of B-sites by halide anions. Lower-symmetry polymorphs (P31c, P63, Pna21, Pca21) are then generated by displacing Li atoms off mirror planes according to soft-mode patterns (Γ2, Γ3, Γ5, M2, M3). Reference compounds Li4SiO4 and the relevant lithium halides (LiF, LiCl, LiBr, LiI) are also constructed. All structures are relaxed using DFT (plane-wave cutoff ≥ 700 eV, k-point spacing ≤ 0.15 Å⁻¹) until forces are below 0.001 eV/Å. Total energies obtained from the relaxations are used to compute decomposition energies ΔE = E(Li6SiO4XX') − [E(Li4SiO4) + E(LiX) + E(LiX')] per atom. For the ground-state Li6SiO4Cl2 structure in space group Pna21, finite-difference phonon calculations (displacement 0.01 Å) give the elastic stiffness matrix, from which the bulk modulus B and shear modulus G are derived via Voigt–Reuss–Hill averaging. All analyses can be performed with open-source tools (e.g., Quantum ESPRESSO for DFT, pymatgen and ASE for structure manipulation).

## Reproduction target
Construct the crystal structures for all compositions Li6SiO4XX' (X,X' = F, Cl, Br, I) in the P63mc space group and their lower-symmetry polymorphs (P31c, P63, Pna21, Pca21). Also build the reference phases Li4SiO4 and LiX (X = F, Cl, Br, I). Perform DFT geometry optimization on every structure. Using the converged total energies, compute the decomposition energy (in meV/atom) for every composition and space group, defined as ΔE = E(Li6SiO4XX') − [E(Li4SiO4) + E(LiX) + E(LiX')]. For the ground-state Li6SiO4Cl2 in the Pna21 structure, compute the elastic stiffness matrix from finite displacements and extract the polycrystalline bulk modulus B and shear modulus G (in GPa) via Voigt–Reuss–Hill averaging. Produce two output files: `decomposition_energies.json` mapping composition_space_group identifiers to their decomposition energies, and `elastic_constants.json` containing the keys `B_DFT` and `G_DFT`.

## Workflow steps

### Step 1: Build initial and lower-symmetry structural models
- Role: process
- Action: Build atomic structures for Li6SiO4XX' compositions (X,X' = F, Cl, Br, I) in the P6_3mc space group, using alternating Li3X and Li3SiO4 layers with half of B-sites occupied by halide. Then generate lower-symmetry polymorphs (P31c, P6_3, Pna2_1, Pca2_1) by displacing Li atoms off mirror planes according to the soft-mode patterns (Γ2, Γ3, Γ5, M2, M3). Also construct reference compounds Li4SiO4, LiX (X=Cl,Br,I,F) in their ground-state structures.
- Evidence: `/app/outputs/structures_manifest.txt`

### Step 2: DFT geometry optimization of all structures
- Role: process
- Action: Perform DFT geometry optimization for every built structure (candidates and references) using Quantum ESPRESSO with PBE functional, plane-wave cutoff ≥700 eV, k-point spacing ≤0.15 Å⁻¹. Relax atomic positions and cell until forces <0.001 eV/Å. Save final total energies for each structure.
- Evidence: `/app/outputs/dft_energies.txt`

### Step 3: Compute decomposition energies
- Role: scored (load-bearing)
- Action: For each Li6SiO4XX' composition and space group, compute decomposition energy ΔE = E(Li6SiO4XX') - [E(Li4SiO4) + E(LiX) + E(LiX')] (in meV/atom). Output a JSON file mapping the design string (e.g., 'Li6SiO4Cl2_Pna2_1') to the energy value.
- Output file: `/app/outputs/decomposition_energies.json`
- Format: json
- Contract: { 'composition_space_group': number }
- Scoring: scored by hidden verifier

### Step 4: Elastic constant calculation for ground-state Li6SiO4Cl2
- Role: process
- Action: Using the DFT-optimized Li6SiO4Cl2 structure in the Pna2_1 space group, perform finite-difference phonon calculations (displacement 0.01 Å) to obtain the elastic stiffness matrix. Compute bulk modulus B and shear modulus G via the Voigt-Reuss-Hill averaging scheme.
- Evidence: `/app/outputs/elastic_calc.log`

### Step 5: Report elastic moduli
- Role: scored (load-bearing)
- Action: Write the computed bulk modulus (B) and shear modulus (G) in GPa to elastic_constants.json.
- Output file: `/app/outputs/elastic_constants.json`
- Format: json
- Contract: { 'B_DFT': 53.0, 'G_DFT': 31.0 }
- Scoring: scored by hidden verifier
